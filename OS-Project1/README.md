# OS Architecture Simulation

A C++17 project that runs one file-copy program on three operating system architectures:

1. Monolithic (Linux-inspired)
2. Strictly layered
3. Modular monolithic

Complete the parts marked `// TODO` and `// YOUR CODE HERE` in `starter_kit/`. Do not change the OSApi interface, the user program, or the tests.

## Build and run

```sh
cd starter_kit
make run
```

The starter code compiles, but tests fail until the missing parts are implemented. The tests print a final PASS/FAIL summary; all of them must pass. CMake is also supported (`ctest --output-on-failure`).

## Submission

Submit the code and build files as `OS-Project1-<StudentNumber>.zip`, keeping the `.git` folder. Design decisions and output are discussed in the oral defense.
